Учебный проект интернет-магазина на Django.

О проекте

Проект создан в рамках учебного курса по разработке на Python и Django.

На данном этапе реализованы:

главная страница интернет-магазина;
страница с контактной информацией;
навигация между страницами;
адаптивная стилизация с использованием Bootstrap;
форма обратной связи;
обработка отправки формы с отображением сообщения об успешной отправке.
Технологии
Python 3.13
Django
Bootstrap 5
SQLite
Установка

Клонируйте репозиторий и перейдите в директорию проекта.

Создайте виртуальное окружение:

python -m venv venv

Активируйте виртуальное окружение.

Для Windows PowerShell:

.\venv\Scripts\Activate.ps1

Установите зависимости:

pip install -r requirements.txt
Запуск проекта

Запустите сервер разработки:

python manage.py runserver

Откройте в браузере:

http://127.0.0.1:8000/
Страницы проекта
Главная страница: /
Контакты: /contacts/
Форма обратной связи

На странице /contacts/ расположена форма обратной связи с полями:

имя;
email;
сообщение.

После отправки формы пользователю отображается сообщение об успешной отправке.
